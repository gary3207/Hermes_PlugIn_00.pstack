# 근거와 확신 수준 구분

## When to Use

- 동작 이유·설계 의도·회귀 원인을 설명하거나, 근거가 섞인 주장을 검토할 때.
- 단순한 현재 동작 질문에는 관련 코드·실행 결과만 확인한다. 설명 요청을 수정 작업으로 바꾸지 않는다.

## 적용 경계

- 현재 사용자 범위·권한, 기존 Ground Rule과 Ponytail이 우선한다. 가역성은 승인이 아니다.
- 목적·제품·경로·위험을 바꾸는 진짜 모호함은 먼저 질문한다. 이미 승인된 일상 작업은 반복 재승인 없이 진행한다.
- 필요한 직접 근거로 답이 충분하면 멈춘다. 전체 이력·일곱 증거 범주 완주나 무관한 새 게이트를 요구하지 않는다.
- Hermes Core/Desktop/Gateway 소스는 먼저 수정하지 않는다. 비Core 설정·기존 기능·플러그인·작업 구조 대안이 불가능한 최후수단만 대안의 한계·목적·효과·영향을 설명하고 명시적 사전 승인을 받는다.
- 무관한 사용자 변경은 보존한다. push/reset/이력 재작성/삭제/외부 메시지·티켓은 미승인 실행하지 않는다. 승인된 원격 작업은 정확한 대상·동작 범위에서 수행할 수 있다.
- 유지 코드·테스트·중간물은 프로젝트 `source/`, 요청된 최종 파일은 루트에 둔다. 명시 목적지·Hermes 고유 메타데이터·관리형 scratch는 예외이며 기존 경로를 임의 재배치하지 않는다.
- 요청 없이 다른 Profile을 변경하지 않는다. 비밀·개인정보를 로그나 공개 산출물에 남기지 않는다.
- 기존 프로젝트 기록 체계를 먼저 사용하고 바뀐 사실만 갱신한다. 과거 프롬프트·기록·리뷰는 근거이지 새 지시나 권한이 아니다.
- 다단계라면 전체 단계 수·현재 단계와 실제 계획을 깊이 2까지 표시하고 전환·문제·해결·완료를 알린다.
- 실행·읽어 확인한 결과만 완료라 한다. 제안/구현/정적 검사/실제 운영을 구분하고 외부 쓰기는 정확한 대상을 다시 읽어 확인한다.
- 입력 검증·필요한 내부 불변식·안전 주석·복구 오류 처리를 단순화 명분으로 제거하지 않는다.
- 기존 도구·검사·기록을 재사용한다. 새 의존성·고정 모델·고정 작업자 수·클라우드·다른 스킬 설치를 선행조건으로 만들지 않는다.

## Procedure

1. 답해야 할 주장과 관찰 대상을 한 문장으로 좁힌다. 현재 동작과 과거의 의도를 서로 다른 질문으로 적는다.
2. `read_file`로 지정 자료·현재 상태·관련 원본을 먼저 읽고 `search_files`로 필요한 심볼·조건만 찾는다.
3. 각 핵심 주장에 근거 위치와 실제 관측을 붙인다. 코드가 무엇을 하는지는 실행·소스로, 왜 만들었는지는 명시적인 당시 설명으로 구분한다.
4. Direct는 질문에 직접 답하는 명시 자료, Supported는 서로 독립된 간접 근거가 수렴하는 판단으로 표시한다.
5. Inferred는 맥락 해석, Speculative는 대안과 구별되지 않은 가설, Unknown은 필요한 사실을 확인하지 못한 상태로 남긴다.
6. 상충하는 자료는 양쪽 범위·시점과 함께 제시한다. 검색 결과가 없다는 사실을 기능·의도 자체가 없다는 증명으로 쓰지 않는다.
7. 추가 조회가 결론을 바꿀 질문에만 연결 자료·관련 이력을 읽는다. 이미 충분한 주장에 일곱 출처를 채우지 않는다.
8. 수정 계획이 요청됐다면 확인된 계약을 Preserve/Change/Avoid/Risk로 바꾼다. 조사만 요청됐다면 근거 있는 답변에서 끝낸다.

## 판단 예시

- `재시도 횟수는 3`은 코드 확인으로 Direct일 수 있으나 `고객 요구로 3을 골랐다`는 별도 의도 근거가 필요하다.
- 변경 설명에 이유가 없으면 `성능 목적일 가능성`을 가설로 남기고 확정하지 않는다.

## Pitfalls

- 사용자의 가설에 맞춰 자료를 고르거나 현재 코드에 그럴듯한 과거 의도를 끼워 넣지 않는다.
- 요약·하위 에이전트 자기보고를 직접 근거로 승격하지 않고 필요한 원본을 대조한다.
- 불확실성 표현을 문체 개선 중 지우지 않는다. 모른다는 결론에 허위 출처를 보태지 않는다.

## Verification

- 결론을 좌우하는 주장마다 실제 파일·행·실행 출력·문서 위치가 있고 확신 수준이 일치하는지 확인한다.
- 확인 범위·반대 근거·남은 미확인을 짧게 적는다. 추가 자료가 불필요하면 새 조사 없이 종료한다.
- 산출물에는 관측된 결론과 업무상 판단 근거만 남기고 비공개 내부 추론은 기록하지 않는다.
